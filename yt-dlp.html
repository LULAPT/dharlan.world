yt-dlp

Monta o comando pra baixar vídeo ou áudio com o yt-dlp. Cola o link, escolhe o formato e roda o comando no terminal do seu PC. Funciona com YouTube e mais uns mil sites.

ainda não tem o yt-dlp instalado?

Precisa do yt-dlp e do ffmpeg — é o ffmpeg que junta áudio e vídeo e converte os formatos.

Windows
winget install yt-dlp.yt-dlp Gyan.FFmpeg
Arch / CachyOS
sudo pacman -S yt-dlp ffmpeg
macOS
brew install yt-dlp ffmpeg

Se um dia parar de baixar do YouTube, quase sempre é o yt-dlp desatualizado: yt-dlp -U (ou atualize pelo gerenciador de pacotes).
